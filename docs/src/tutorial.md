# Illustrated tutorial

We will make a time series and an image in two ways: Gaussian coefficients shaped
by a power spectrum, and Laplace coefficients synthesized through wavelets. All four
figures are generated by the code on this page during the documentation build.
Install the [development checkout and documentation environment](installation.md)
to run these examples. CairoMakie renders the figures without a display or GPU.

## 1. Gaussian coefficients to a correlated time series

Think of the first array as independent controls for frequency modes. A power law
sets their relative strengths. Multiplying by **the square root of power** changes
those controls into the desired mode amplitudes. The orthonormal Hartley transform
then turns them into samples along a time or position axis.

```@example tutorial
using StationaryRandomFields, Distributions, Random, CairoMakie
CairoMakie.activate!(; type = "svg")
set_theme!(Theme(; fontsize = 16))

rng = MersenneTwister(12)
latent = UnivariateGaussianRandomField(Float64, (256,))
z = rand(rng, latent)
grid = FieldGrid(size(z); spacing = (1.0,))
power = 0.05^2 * SinglePowerLaw{1}(-2.0)
spectral = prepare(SpectralScaling(grid, power), z)
hartley = prepare(HartleyTransform(size(z)), z)
scaled = apply(spectral, z)
signal = apply(hartley, scaled)
logprior = logpdf(latent, z)

frequency = (1:127) ./ 256
power_values = [power_point(power, f) for f in frequency]
fig = Figure(; size = (1000, 650))
ax = Axis(
    fig[1, 1]; title = "1. Independent Gaussian coefficients",
    xlabel = "Packed frequency-mode index", ylabel = "Coefficient"
)
lines!(ax, eachindex(z), z; color = :steelblue)
ax = Axis(
    fig[1, 2]; title = "2. Chosen power spectrum",
    xlabel = "Frequency [cycles / sample]", ylabel = "Discrete power",
    xscale = log10, yscale = log10
)
lines!(ax, frequency, power_values; color = :darkorange, linewidth = 2)
ax = Axis(
    fig[2, 1]; title = "3. Coefficients after spectral scaling",
    xlabel = "Packed frequency-mode index", ylabel = "Coefficient"
)
lines!(ax, eachindex(scaled), scaled; color = :steelblue)
ax = Axis(
    fig[2, 2]; title = "4. Correlated signal after FHT",
    xlabel = "Time [sample units]", ylabel = "Signal [arbitrary units]"
)
lines!(ax, 0:255, signal; color = :purple, linewidth = 2)
save("gaussian-1d.svg", fig)
nothing # hide
```

![Four stages of one-dimensional Gaussian spectral synthesis](gaussian-1d.svg)

The first and third panels show **frequency coefficients**, not light curves. The
last panel is the signal. Power follows an inverse-square law in frequency here, so slow changes
are stronger than rapid ones. Zero DC power removes the constant mode. The plot
shows the target power, not the periodogram of this single draw; individual draws
fluctuate around the target in power. The reference frequency `0.05` sets an amplitude
convention for this example, rather than a universal physical normalization.

The finite grid is periodic: the signal wraps around at its boundary. When using
these samples as a light-curve noise model, choose the grid extent, cadence, and
spectral cutoffs for your observation. See [Timmer & König (1995)](https://ui.adsabs.harvard.edu/abs/1995A%26A...300..707T/abstract)
for the original time-series motivation and [Mathematical Basis](math.md) for the
package's discrete-power convention.

## 2. The same construction in two dimensions

Only the array shape and spectrum rank change. A mode now has two frequency
coordinates, and the output can be an image or a phase screen.

```@example tutorial
latent = UnivariateGaussianRandomField(Float64, (128, 128))
z = rand(MersenneTwister(23), latent)
grid = FieldGrid(size(z); spacing = (1.0, 1.0))
power = 0.04^3 * SinglePowerLaw{2}(-3.0)
spectral = prepare(SpectralScaling(grid, power), z)
hartley = prepare(HartleyTransform(size(z)), z)
scaled = apply(spectral, z)
signal = apply(hartley, scaled)

function field_panel!(slot, values, title, xlabel, ylabel; colormap = :balance)
    ax = Axis(slot[1, 1]; title, xlabel, ylabel, aspect = DataAspect())
    image = heatmap!(ax, values; colormap)
    Colorbar(slot[1, 2], image)
    return ax
end

fig = Figure(; size = (1050, 850))
field_panel!(fig[1, 1], z, "1. Gaussian latent coefficients", "Mode index 1", "Mode index 2")
# Center frequencies only for display; execution uses unshifted mode ordering.
shown_power = circshift(power_map(power, grid), (64, 64))
field_panel!(
    fig[1, 2], log10.(max.(shown_power, 1.0e-8)),
    "2. Log10 power (DC clipped for display)", "Centered mode index 1", "Centered mode index 2";
    colormap = :viridis
)
field_panel!(fig[2, 1], scaled, "3. Spectrally scaled coefficients", "Mode index 1", "Mode index 2")
field_panel!(fig[2, 2], signal, "4. Correlated signal after FHT", "Pixel x", "Pixel y")
save("gaussian-2d.png", fig)
nothing # hide
```

![Four stages of two-dimensional Gaussian spectral synthesis](gaussian-2d.png)

The color bars use each panel's own units and range. The central dark pixel of the
power map is the zero DC mode; its logarithm is clipped only for plotting. The
increasing power toward small nonzero frequencies produces broad structure in the
signal. To introduce anisotropy, use `stretched` and `rotated` spectra. To limit the
frequency band, use `SaturatedPowerLaw`.

This is a useful building block for correlated radio-image priors, as motivated by
[Arras et al. (2021)](https://doi.org/10.1051/0004-6361/202039258) and
[Tiede et al. (2026)](https://arxiv.org/abs/2511.17706), although their full imaging
models differ. With an appropriate phase power spectrum it can also generate the
screen component of an Sgr A* scattering model
([Johnson 2016](https://arxiv.org/abs/1610.05326)), or an empirical atmospheric phase
screen for interferometry. This illustration is not a calibrated scattering simulation:
a propagation model and physical units must be added separately.

A spectrum can be updated without rebuilding the Hartley plan:

```@example tutorial
updated = 2.0 * power + ConstantPowerSpectrum{2}(0.01)
updated_signal = apply(hartley, apply(spectral, z, updated))
size(updated_signal)
```

## 3. Laplace coefficients to a one-dimensional wavelet signal

Now coefficients represent features at different locations and scales. A Laplace
prior prefers small coefficients, with heavier tails than a Gaussian of the same
variance. Wavelet synthesis assembles these features into the signal. Here we use
the default periodic Haar wavelet, whose basis functions make step-like features.

```@example tutorial
latent = UnivariateLaplaceRandomField(Float64, (256,); b = 0.2)
z = rand(MersenneTwister(34), latent)
synthesis = prepare(WaveletTransform(size(z); levels = 4), z)
signal = apply(synthesis, z)
logprior = logpdf(latent, z)

fig = Figure(; size = (1000, 370))
ax = Axis(
    fig[1, 1]; title = "Independent Laplace coefficients",
    xlabel = "Packed wavelet-coefficient index", ylabel = "Coefficient"
)
stem!(ax, eachindex(z), z; color = :steelblue, markersize = 3)
ax = Axis(
    fig[1, 2]; title = "Signal after Haar wavelet synthesis",
    xlabel = "Position [sample units]", ylabel = "Signal [arbitrary units]"
)
lines!(ax, 0:255, signal; color = :purple)
save("laplace-1d.svg", fig)
nothing # hide
```

![Laplace coefficients and their synthesized one-dimensional signal](laplace-1d.svg)

The coefficient array is packed by wavelet scale; adjacent entries do not all
represent adjacent signal positions. Independent, equally scaled coefficients need
not produce a smooth signal. Sparsity promotion is a prior preference used during
inference, rather than a guarantee that a random draw contains exact zeros.

## 4. A two-dimensional wavelet prior with stronger coarse scales

For an image, we can additionally give broad features more amplitude than fine
texture. `ScaleTransform` weights coefficients before wavelet synthesis. In the
periodic packing used here, the approximation coefficients occupy the low-index
corner at each level; the loop assigns larger weights to successive coarse corners.

```@example tutorial
latent = UnivariateLaplaceRandomField(Float64, (128, 128); b = 0.2)
z = rand(MersenneTwister(45), latent)
levels = 4
weights = fill(0.1, size(z))
for level in 1:levels
    width = size(z, 1) ÷ 2^level
    weights[1:width, 1:width] .= 0.1 * 2.0^level
end
transform = TransformChain(
    ScaleTransform(size(z), weights), WaveletTransform(size(z); levels)
)
synthesis = prepare(transform, z)
signal = apply(synthesis, z)
logprior = logpdf(latent, z)

fig = Figure(; size = (1200, 390))
field_panel!(fig[1, 1], z, "1. Laplace latent coefficients", "Packed index 1", "Packed index 2")
field_panel!(fig[1, 2], weights .* z, "2. Coefficients with scale weights", "Packed index 1", "Packed index 2")
field_panel!(fig[1, 3], signal, "3. Wavelet-synthesized signal", "Pixel x", "Pixel y")
save("laplace-2d.png", fig)
nothing # hide
```

![Laplace coefficients, scale weighting, and a two-dimensional wavelet signal](laplace-2d.png)

This supplies a possible prior for sparse Bayesian image reconstruction: constrain
wavelet coefficients through `logpdf(latent, z)` and compare the synthesized image
with observations through your likelihood. The scale weights are deterministic
amplitude weights, not a Fourier power spectrum. With this parameterization the prior
is evaluated on the original `z`, before weighting. For a direct image-space Laplace
prior instead, use `IdentityTransform(size(z))`.

## Sampling a transformed field

```julia
field = TransformedRandomField(latent, synthesis)
x = rand(field)
```

`logpdf(field, x)` is deliberately unavailable. Evaluate `logpdf(field.latent, z)`.
For a vector-valued field, `rand(field, n)` follows Distributions' matrix-of-columns
convention; higher-rank fields use arrays of sample arrays. `rand!(rng, field, batch)`
also accepts a numeric array whose trailing axes index independent samples.

## Differentiation and compiled execution

Prepare transforms outside the objective and keep random draws fixed during AD.
`examples/latent_inference.jl` contains a complete latent log-posterior example.
The CPU Enzyme suite checks latent, wavelet, Hartley, and spectral-parameter gradients.

For Reactant, transfer the latent array, prepare using that array as the prototype, and
compile `apply` or the objective. Trainable parameters should be device arrays, not Julia
scalar constants. A scalar parameter can be represented by a one-element array and
reduced with `sum`, avoiding scalar indexing. When constructing a dynamic positive
constant spectrum with `exp(sum(parameters))`, use `check_args=false` to keep host
validation outside the compiled objective. Validate physical parameter ranges before
compilation and use positive parameterizations for optimization.

CPU and CUDA sampling use backend-specific RNGs. Compiled Reactant sampling uses an
explicit `ReactantRNG`, preserving state between calls. RNG streams and sample values
need not match between backends; numerical transforms are compared with fixed inputs.

For trainable spectrum geometry, construct modifiers with
`Stretch(exp(logwidth1), exp(logwidth2); check_args=false)` and `Rotate(angle)`,
then combine them with `modify`. The compiled gradient suite checks both widths and
the two-dimensional rotation angle against finite differences. Static proper rotation
matrices support arbitrary spectrum rank.
